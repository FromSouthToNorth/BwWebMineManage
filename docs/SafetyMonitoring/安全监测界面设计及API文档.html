    二、设计对标标准

    本界面设计依据以下国家安全生产行业标准：

    标准号名称年份角色
    AQ 6201煤矿安全监控系统通用技术要求2019（替代 2006）功能需求来源
    AQ 1029煤矿安全监控系统及检测仪器使用管理规范2019（替代 2007）传感器设置 + 运维规范

    AQ6201-2006 → AQ6201-2019 关键变化

    指标2006 版2019 版提升
    最大巡检周期≤30s≤20s↑33%
    双机切换时间≤5min≤60s↑80%
    备用电源≥2h≥4h↑100%
    传输处理误差≤1.0%≤0.5%↑50%
    误码率≤10⁻⁸≤10⁻⁹↑90%
    实时数据存储≥7d≥3 个月↑13×
    历史记录存储≥1 年≥2 年↑100%
    故障数据丢失≤5min≤60s↑80%
    主机切换手动/自动双机热备自动架构升级
    加密存储无RSA 加密新增
    分站容量8/16/32/64/128+256扩展
    无线传感器无≥100m 距离, ≥24h 电池新增
    煤与瓦斯突出无§§5.5.2.3/2.4新增
    分级/逻辑报警无§§5.6.12.3/12.4新增
    应急联动无§5.5.2.7新增
    数据应用分析无§5.5.17新增

    AQ1029-2007 → AQ1029-2019 关键变化

    变化项2007 版2019 版
    传感器防护等级无要求气体类 ≥IP65，其余 ≥IP54
    突出矿井甲烷传感器无特殊要求必须全量程/高低浓度，宜激光原理
    主干线缆无要求必须分设两条，不同井筒入井
    甲烷传感器调校周期每 10d每 15d（催化原理）/ 每 6 个月（激光原理）
    甲烷电闭锁测试周期每 10d每 15d，可能停电的每 半年
    双机备份双机或多机双机热备，60s 切换，不得用虚拟机
    UPS 时长2h4h
    光纤共用无要求不得与图像监视共用同一芯光纤
    伪数据标注/大数据分析无必须支持
    应急联动无超限断电时自动联动广播/通信/定位
    中心站显示终端调度室调度室（强调）
    风速传感器回风巷测风站+突出煤层采煤工作面回风巷和掘进巷道回风流
    风向传感器无新增（突出煤层进风巷/分风口），逆转时声光报警
    粉尘传感器无新增（采煤机/掘进机/转载点等）
    压风机温度传感器无新增（温度超限声光报警+断电）

    九、数据流

    onMounted
│
├─ fetchAll()   ← 并行拉取三路数据
│   ├─ listSafetyMonitoring(1954, pageNum=1, pageSize=500) → 首次拉取
│   │   └─ 循环 p=2..totalPages 拉取剩余页 → 全量 monitorItems
│   ├─ getKpiData(8453, data)            → kpi 统计
│   └─ getData(1942, data)               → 分类统计 (catCategories, catValues)
│
├─ fetchAlarms() ← 独立拉取报警
│   └─ listEalTimeAlarm(1960, page)       → alarmFeed (AlarmItem[])
│
│  前端处理 (每次 fetchAll 后):
│   ├─ buildStateText(item, unit, dv)    → categoryStateText (展示文本)
│   │    回退链: categoryStateText → stateText → valueText
│   │          → "dv.toFixed(2) + unit" → statusTxt/state → ''
│   ├─ parseNumeric(detectionVal)        → dv (NaN 守卫 → 0)
│   ├─ getAlarmLevel(item, rawAlarmType) → _alarmLevel (0-4)
│   │    综合判定: alarmType == 1 || statusTxt === '报警'
│   │           || state === '报警' → determineAlarmLevel()
│   ├─ checkOutburstConditions(items)    → outburstConditions
│   │    区域分组 + Lv≥3 多传感器级联 + 风速/风向/风机
│   └─ buildFeedStatusData(items)        → feedItems
│        matchTask() 匹配馈电传感器 → 正常/异常/断电/离线
│        后备: 从报警传感器推导馈电状态
│
└─ setInterval(10s) → 重复 fetchAll + fetchAlarms

    Lv4突出紫 #a855f7闪烁多传感器+风流逆转等联合条件

    判断依据（src/constants/kpi.ts → determineAlarmLevel()）：

    function determineAlarmLevel(value, alarmThreshold, cutoffThreshold, changeRate) {
  if (value < alarmThreshold) return LEVEL_0
  if (value < cutoffThreshold) return LEVEL_1
  if (changeRate > 0.1) return LEVEL_3
  return LEVEL_2
}

    • 响应式分页 — 使用全局 <Pagination> 组件，支持 [20, 50, 100, 200, 500] 页大小，layout="total, sizes, prev, pager, next, jumper"

    19.1 SDK 引入

    19.2 全局对象

    引入后在 window 上生成 BW_SSO_SDK，包含两个方法：

    方法参数说明
    BW_SSO_SDK.SSOLoginhostname, port, callback单点登录
    BW_SSO_SDK.SSOLogouthostname, port退出登录

    19.3 登录流程

    入口： src/main.ts → 应用挂载前调用 bwSSOSDKLogin(callback)

    bwSSOSDKLogin(callback)
├─ URL 含 mine_key 参数？
│   └─ 是 → 直接 callback()，跳过 SSO
│
├─ window.BW_SSO_SDK 可用？
│   └─ 否 → console.warn，不挂载应用
│
└─ BW_SSO_SDK.SSOLogin(hostname, port, callback)
    └─ 成功 → callback() → 挂载 Vue 应用
    └─ 失败 → callback() → 继续挂载（后续由 permission.ts 拦截处理）

    19.4 调用示例

    登录：

    BW_SSO_SDK.SSOLogin(
  window.location.hostname,  // "192.163.5.10"
  window.location.port,      // "8080"
  (data) => {
    if (!data) return
    // data 结构
    // {
    //   "userInfo": {
    //     "username": "JQDWXT",
    //     "realname": "管理员(JQDWXT)",
    //     "mineName": "精确定位系统",
    //     "mineDesc": "JQDWXT"
    //   }
    // }
    console.log(data.userInfo.username)  // "JQDWXT"
    console.log(data.userInfo.mineName)  // "精确定位系统"
  }
)

    退出登录：

    BW_SSO_SDK.SSOLogout(
