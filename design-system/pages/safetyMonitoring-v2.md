## 4. 组件详细设计

### 4.1 TrendChart（趋势曲线）— AQ6201-2019 §5.6.9

**当前问题：**
- 无游标交互，无法精确读值
- 门限线固定在系列上，无法单独配置
- 只显示全局平均值，不能按传感器选择

**改造方案：**

```typescript
// 新增交互特性
interface TrendChartProps {
  // ...existing
  enableCursor?: boolean       // 启用游标
  cursorSnap?: boolean         // 游标吸附到数据点
  showThresholdZones?: boolean // 显示门限区域色块
  gradeColors?: boolean        // 分级着色（超过不同门限不同色）
  showMarkers?: boolean        // 数据点标记（报警点高亮）
}
```

**游标实现（AQ6201-2019 §5.6.9）：**
- ECharts `dataZoom` + `markLine` 联动
- 鼠标悬浮时显示十字准线 + 数据面板
- 面板内容：时刻、监测值、最大值、平均值、最小值、断电起止时刻及累计时间、报警起止时刻及累计时间、馈电异常起止时刻及累计时间

**门限区域色块：**
- 报警门限 ~ 断电门限：黄色半透明区域
- 断电门限以上：红色半透明区域
- 用户可一目了然当前值处于哪个区间

---

### 4.2 StationMatrix（分站监测矩阵）— AQ6201-2019 §5.5.5.6

**当前问题：**
- 树图子节点全部等宽（value=1），无法反映传感器数量分布
- 馈电状态不可见
- 分组层级有限

**改造方案：**
- leaf 节点 value 改为传感器数量，区域块大小反映监测点密度
- 添加馈电状态图标叠加（小圆点标记在右上角）
- 支持三级钻取：区域 → 分站 → 传感器

**tooltip 增强：**
- 增加断电范围显示
- 增加馈电状态异常标记
- 增加最近一次报警/解除报警时刻

---

### 4.3 CategoryBar（分类统计）— 新增分级着色

**改造方案：**
- 报警类别的柱条使用对应分级色（L2-L4）
- 正常类别保持主色渐变
- 柱条右侧添加小标签显示报警级别分布（如 "L2:3 L3:1"）

---

### 4.4 StatusRing（安全状态分布）— 新增分级分解

**改造方案：**
- 外环：正常/报警/故障 分布（现有）
- 内环/展开：报警分级分解（L1 预警 / L2 报警 / L3 紧急 / L4 突出）
- 点击分级可筛选对应级别监测点

---

### 4.5 GradeAlarmPanel（分级报警面板）— 新增，AQ6201-2019 §5.6.12.3

**功能：**
- 按报警级别分组展示当前活跃报警
- 每个级别显示：数量、变化趋势、持续最长时间
- L3/L4 级别自动展开，L1/L2 可折叠
- 逻辑报警摘要（AQ6201-2019 §5.6.12.4）

**布局：**
```vue
<GradeAlarmPanel>
  ├── L4 突出危险 (count) — 红色闪烁
  ├── L3 紧急 (count) — 橙色脉冲
  ├── L2 报警 (count) — 红色
  └── L1 预警 (count) — 黄色
```

---

### 4.6 SwitchStateChart（开关量状态图）— 新增，AQ6201-2019 §5.6.10

**功能：**
- **状态图：** 直线表示开关量状态随时间变化（开/停）
- **柱状图：** 单位时间开机效率直方图
- **游标：** 对应区间起止时刻、报警及断电状态、馈电状态
- **屏幕上方：** 传感器设置地点、所测物理量名称、起止日期和时间

**使用 ECharts 组合图：**
- 上方：状态图（自定义 series 用直线段表示）
- 下方：柱状图（开机效率）
- 联动 dataZoom

---

### 4.7 FeedStatusPanel（馈电状态监测）— 新增，AQ1029-2019 §9.2.2

**功能：**
- 列表显示所有馈电传感器状态
- 异常项标红 + 发光
- 断电命令 vs 实际馈电状态比对
- 异常起止时刻 + 累计时间

**数据字段：**
```
地点 | 名称 | 断电区域 | 断电命令 | 馈电状态 | 异常累计时间 | 起止时刻 | 措施
```

---

### 4.8 AlarmTimeline（实时告警）— AQ6201-2019 §5.6.12.2

**增强：**
- 每条告警前加分级色标（L1-L4 badge）
- 馈电异常告警特殊标记
- 点击可查看详情/确认
- 声音提示（新报警时播放提示音）

  | 'switch_feed_abnormal'  // 开关量馈电异常日(班) §5.6.14.6

### 4.10 OutburstWarning（突出预警）— AQ6201-2019 §5.5.2.3/§5.5.2.4

**增强：**
- 掘进工作面突出报警条件（§5.5.2.3）:
  - 条件a: 甲烷浓度迅速升高 + 风速不低于正常值 → 切断相关区域电源
  - 条件b: 甲烷浓度迅速升高 + 风流逆转 → 切断相关区域电源
  - 条件c: 工作面 + 回风 + 进风 浓度均迅速升高 → 切断相关区域电源
- 采煤工作面突出报警条件（§5.5.2.4）:
  - 条件a: 浓度迅速升高 + 风流逆转
  - 条件b: 浓度迅速升高 + 回风进风均升高
- 显示当前触发的具体条件组合

## 5. 数据流设计

```
API (每10s轮询)
  ├── listSafetyMonitoring()  →  monitorItems
  │     ├── map fields (per AQ6201-2019 §5.5.5.1)
  │     ├── determineAlarmLevel() → L0-L4
  │     └── checkOutburstConditions() → OutburstWarning
  │
  ├── getKpiData()  →  kpi (总/报警/正常/故障/标校)
  │
  ├── getData()  →  catCategories + catValues
  │
  ├── listEalTimeAlarm()  →  alarmFeed
  │
  └── [New] getFeedStatus()  →  feedPanel data
        └── listSwitchStates()  →  switchChart data

State Management (Pinia or local ref):
  - monitorItems → StationMatrix, CategoryBar, TrendChart, StatusRing
  - kpi → HeroCards, StatusRing
  - alarmFeed → AlarmTimeline
  - outburstConditions → OutburstWarning
  - feedStatus → FeedStatusPanel
  - switchStates → SwitchStateChart
```
